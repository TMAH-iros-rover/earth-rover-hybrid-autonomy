# Earth Rover camera calibration

Earth Rover SDK의 `/v2/front` 또는 `/v2/rear` 이미지를 이용해 체커보드
내부 파라미터와 렌즈 왜곡 계수를 계산하는 도구입니다. SDK 서버와 미션이 먼저
실행되어 카메라 API가 응답해야 합니다.

## 설정

`calibration_config.json`에서 SDK 주소, 카메라, 체커보드 규격, 저장 경로를
관리합니다. 현재 기본 규격은 내부 코너 `7 x 10`, 한 칸 `25 mm`입니다. 경로는
설정 파일이 있는 폴더를 기준으로 해석됩니다. 명령행 옵션을 지정하면 설정 파일의
값보다 우선합니다.

## 1. 이미지 수집

기본 설정은 현재 사용하는 체커보드 규격인 내부 코너 가로 7개, 세로 10개와
한 칸 25 mm입니다.

```bash
cd /home/jiwon/earth-rover-hybrid-autonomy/calibration
python3 capture_checkerboard.py
```

조작키:

- `Space`: 코너가 검출된 현재 원본 프레임 저장
- `D`: 마지막 저장 프레임 삭제
- `C`: 지금까지 저장한 프레임으로 캘리브레이션
- `Q` 또는 `Esc`: 종료

화면 중앙뿐 아니라 네 모서리, 가까운 거리와 먼 거리, 좌우 및 상하로 기울인
자세를 포함해 30~50장을 수집하는 것을 권장합니다. 같은 자세의 연속 프레임을
반복 저장하지 마십시오.

## 2. 별도 캘리브레이션

수집 화면에서 `C`를 누르는 대신 다음 명령으로도 계산할 수 있습니다.

```bash
python3 calibrate_camera.py
```

최소 10개 유효 이미지를 요구하며 30~50개를 권장합니다. 해상도가 다른 이미지와
코너 검출에 실패한 이미지는 결과 JSON의 `rejected_images`에 기록됩니다.

## 3. 실시간 검증

```bash
python3 verify_calibration.py
```

왼쪽에 원본, 오른쪽에 왜곡 보정 영상을 표시합니다. 기본 `alpha`는 현재 렌즈에서
유효 영상을 안정적으로 표시하는 `0.0`입니다. `alpha`를 높이면 원래 시야를 더
보존하지만 렌즈와 왜곡 모델에 따라 넓은 검은 영역이 생길 수 있습니다.

## 결과 데이터

`results/front_camera.json`에는 카메라 행렬, OpenCV 순서의 왜곡 계수
`[k1, k2, p1, p2, k3]`, 캘리브레이션 해상도, RMS 오차, 이미지별 재투영
오차가 저장됩니다. 운영 영상의 화면비가 달라지면 이 값을 재사용하지 말고 해당
해상도로 다시 캘리브레이션해야 합니다.
